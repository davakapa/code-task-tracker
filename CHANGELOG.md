# История изменений

## Следующий этап — дерево задач проекта

- Добавлена панель CodeTask Tracker в Explorer с группировкой по файлам.
- Поиск охватывает C/C++ файлы во всех папках открытого проекта.
- Нажатие на задачу открывает файл и выделяет метку.
- Добавлены значки и цвета типов, обновление после правок и изменений файлов.
- Устаревшие результаты не перезаписывают новые; переход по устаревшей позиции отменяется.
- Добавлены пределы сканирования и сообщения о пропущенных файлах.
- Интеграционные тесты проверяют дерево, навигацию, правки, создание, переименование,
  удаление и несколько корневых папок.

## Поиск в текущем файле

- Добавлен парсер пяти типов меток и трёх приоритетов для C/C++.
- Добавлена команда поиска по текущему тексту, включая несохранённые изменения.
- Результаты с позициями выводятся в Output → CodeTask Tracker.
- Добавлены пример, тесты парсера и проверки команды в VS Code.
- Описаны поддерживаемый формат и ограничения начального парсера.

## 0.0.1 — базовый проект

- Проект создан через Yeoman (`generator-code`): TypeScript, esbuild, npm.
- Добавлена команда «CodeTask Tracker: Проверить запуск».
- Описаны запуск, структура и следующие этапы разработки.
